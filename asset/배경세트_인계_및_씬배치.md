# 최종 확정 배경세트 인계 및 씬 배치

## 1. 인계 범위

- 업로드 대상 원본: `asset/심사역은_마법소녀가_되었다_최종확정_배경세트.zip`
- 이 묶음은 **제작 원본 인계용**이다.
- 압축 해제본 배치, 파일 변환·rename, `public/assets/` 복사, 시나리오·catalog 연결, 문서 상태 변경, 커밋·푸시는 개발 담당자가 별도 브랜치에서 수행한다.
- 코드 꼬임 방지를 위해 현재 작업에서는 ZIP과 이 인계 문서 외 파일을 수정하지 않는다.

## 2. 원본 확인 정보

- SHA-256: `C4F6AD44F38C5CBC680937F01996F1FD145329DA5FF93CB8541DBB828FB887CF`
- ZIP 크기: `33,378,690 bytes`
- 실제 구성: 배경 PNG 16장 + `manifest.txt` 1개
- 이전 전달 수량 17종과 달리 현재 ZIP에서 확인된 배경은 16장이다. 누락 여부는 개발 통합 전에 제작 담당자와 확인한다.
- `BG-02`는 `1448×1086`; 나머지 15장은 `1672×941`이다.
- 이미지는 PNG이며 약 1.7~2.5MB/장이다. 현재 production 계약인 `1920×1080 WebP, 500KB 이하` 변환 전 원본이다.
- ZIP 내부 일부 한글 파일명은 압축 도구에 따라 깨질 수 있다. 개발자는 ASCII 식별자 `BG-01`~`BG-07`, `TITLE`을 기준으로 식별하고 최종 파일명은 계약 문서에 맞춰 결정한다.

# 0. 작품 기준

## 한 줄 정의

반복되는 심사에 지쳐 모든 게임을 비슷하게 보기 시작한 심사역 한도윤이, 실망하기 싫어 더는 기대하지 않으려는 마음에서 태어난 회색 망령과 싸우며 끝까지 확인한 뒤 판단하는 태도를 되찾는 음성 인터랙티브 마법소녀 코미디.

## 핵심 질문

> 비슷하다고 판단하는 것과, 보기 전에 의미 없다고 단정하는 것은 같은가?

## 작품의 답

> 비슷하다고 판단하는 것과, 보기 전에 의미 없다고 단정하는 것은 다르다.

도윤은 심사 기준을 버리지 않는다. 완성도와 차별성의 부족을 솔직히 지적하되, 평가표만 보고 결론 내리지 않고 작품의 핵심 경험을 끝까지 확인한다.

## 세 인물의 성장선

- 도윤: 냉소적인 심사역에서 끝까지 확인한 뒤 판단하는 심사역으로 변한다.
- 주노: 상대에게 정답을 재촉하는 안내자에서 상대의 답을 기다리고 받아들이는 동료로 변한다.
- 회색 망령: 비평이나 부정적 평가의 화신이 아니다. 다시 실망하기 싫어서 기대 자체를 포기하려는 체념이다.

비판과 심사는 악이 아니다. 작품은 무조건적인 긍정을 정답으로 제시하지 않는다.

# 1. 등장인물

## 한도윤

- 30대 초반의 게임 심사역.
- 플레이어가 직접 음성으로 대답하는 주인공.
- 건조하고 현실적이지만 타인의 노력을 함부로 조롱하지 못한다.
- 투덜거리면서도 제출물을 직접 실행하고 핵심 경험을 끝까지 확인한다.
- 과거 회사에서 작은 게임 `happy_break`를 만든 경험이 있다.
- 자신의 작품이 묻힌 뒤 평가 업무로 물러났다.
- 도윤의 일반 대사는 고정 재생하지 않는다.
- 문서 속 도윤 대사는 플레이어 발화 예시이며 정답 문장이 아니다.
- 변신·전투·필살기 주문만 정확한 낭독을 요구한다.

## 주노

- 손바닥 크기의 설렘 안내자.
- 반말 고정.
- 한 응답은 최대 두 문장.
- 밝고 자신만만하지만 또다시 선택에 실패할까 두려워한다.
- 평소에는 빠르고 크게 말하고, 진심을 말할수록 조용해진다.
- 도윤을 밀어붙이는 존재에서 도윤의 답을 기다리는 동료로 성장한다.
- 도윤을 선택한 이유는 긍정적인 말을 했기 때문이 아니다. 투덜거리면서도 작품을 끝까지 직접 확인하는 행동 때문이다.

## 회색 망령

- 사람들이 기대했다가 접어 둔 마음과 반복된 실망에서 생긴 존재.
- 지친 체념과 무감각을 상징한다.
- 비평이나 부정적 심사평 자체를 부정하지 않는다.
- 도윤의 기억을 읽지 않는다.
- 심사 시스템, 회사 계정 아카이브, 평가 기록과 남은 감정의 흔적을 이용한다.
- 도윤을 죽이기보다 “기대하지 않으면 실망하지 않는다”는 자신의 논리를 인정받으려 한다.
- 대사는 느리고 끊기며 느낌표를 사용하지 않는다.

## 검은 마법소녀

- 여성.
- 내부 임시 이름은 ‘노아’지만 본편에서는 이름을 공개하지 않는다.
- 타인의 기대와 설렘을 의도적으로 통제하고 차단한다.
- 본편 중간에는 개입하지 않는다.
- GOOD/HIDDEN 이후 post-credit에서만 명확히 등장한다.
- 주노는 그녀의 정체를 확신하지 못한다.
- 오래된 원형 주문, 지팡이 문양, 회색 잔향 흡수 방식을 보고 과거와의 관련성만 의심한다.

# 2. 전체 흐름

```text
N0  반복되는 심사와 happy_break 무언 복선
 ↓
N1  첫 음성 입력
 ↓
N2  주노 등장, 첫 관계 형성, 도윤 선택 이유
 ↓
N3  회색 망령 등장과 자유 대화
 ↓
N4  변신 직전 관계 확인
 ├─ A 죽이 맞는 콤비
 ├─ B 마지못한 협력
 └─ C 서먹함
       ├─ 관계 회복
       └─ 거리 유지
 ↓
N5  변신 주문
 ↓
N6  첫 행동: 방어 또는 공격
       └─ 조건부 두 번째 주문 기회
 ↓
N7  과거 프로젝트와 핵심 자유 음성 질문
       ├─ BELIEVE
       ├─ POSSIBILITY
       └─ CYNIC
 ↓
N8  주노의 주문 / 자기만의 주문 / 거절
 ↓
GOOD / NORMAL / BAD / HIDDEN
       └─ GOOD/HIDDEN post-credit stinger
```

## 예상 플레이타임

v3는 N2 설명과 N4 반복을 줄였지만, 자유 발화와 음성 재시도 시간은 플레이어마다 다르다.

| 구간 | 문서상 상호작용 | 임시 예상 |
|---|---:|---:|
| N0~N1 | 자유 발화 1~2회 | 40~70초 |
| N2~N4 | 자유 발화 2~4회 | 70~130초 |
| N5 | 주문 2개·재시도 가능 | 40~80초 |
| N6 | 첫 주문 1개·조건부 추가 1개 | 45~90초 |
| N7~N8 | 핵심 자유 발화 1~2회·최종 주문 | 70~130초 |
| 엔딩 | 고정 진행 | 30~60초 |
| 합계 | 약 8~12개 상호작용 | 약 5~9분 추정 |

실제 플레이 측정 전 “5분 보장”으로 표기하지 않는다.

# 3. 공통 연출 원칙

1. 자유 대화 구간에는 고정 선택지 버튼을 기본 노출하지 않는다.
2. 음성 모드는 자유 발화를 기본으로 한다. 클릭 모드에서만 동등 의미의 선택지를 fallback으로 제공한다.
3. 문서의 플레이어 발화 예시는 분류 예시이지 정답 문장이 아니다.
4. 주노는 플레이어의 표현을 요약해 받아치되, 플레이어가 말하지 않은 감정을 단정하지 않는다.
5. 같은 노드로 합류하더라도 성공·실패·거절과 관계 상태에 따라 주노의 표정과 행동이 달라진다.
6. N7에서는 게이지, 채점 수치, 정답 예시를 숨긴다.
7. 검은 마법소녀는 GOOD/HIDDEN post-credit 전까지 화면·대사·실루엣으로 암시하지 않는다.
8. 타이틀과 N0 첫 두 화면 독백만 도윤 이미지를 숨긴다. N0 세 번째 문장부터는 일부 전환 독백을 제외하고 도윤 이미지를 계속 표시한다.
9. 도윤 이미지는 대사를 대신하지 않는다. 플레이어 발화는 음성·클릭 입력으로 처리하고 이미지는 현재 감정과 행동만 보조한다.
10. 같은 배경이 유지되는 연속 대사에서는 배경 전환 효과를 반복하지 않는다. 실제 배경이 바뀔 때만 짧은 교차 페이드를 사용한다.
11. 비판적 평가를 악당의 언어로만 처리하지 않는다. 망령의 문제는 평가 내용이 아니라 확인하기도 전에 의미 없다고 단정하는 태도다.

## 연출 메모 태그

- `[POSE]`: 캐릭터 행동·표정·실루엣 variation 후보. 실제 asset ID는 별도 audit에서 확정한다.
- `[CUT]`: 독립 일러스트 가치가 높은 장면 후보. 이 문서에서 새 파일명을 확정하지 않는다.
- `[PRESENTATION]`: 기존 배경, DOM/CSS, particle, timing으로 처리 가능한 연출.

## 도윤 이미지 사용 매핑

| 구간 | 기존 이미지 후보 | 표시 원칙 |
|---|---|---|
| 타이틀, N0 1~2번째 문장 | 없음 | 배경과 평가 문장으로 도입한다. |
| N0 3~4번째 문장 | `char_doyun_normal_tired.png` | 지친 심사 상태. 이 지점부터 도윤이 화면에 등장한다. |
| N0 마지막 문장, N1, N2 첫 등장 | `char_doyun_normal_startled.png` | 정체불명의 목소리와 주노 등장에 반응한다. |
| N2 후속 설명 | `char_doyun_normal.png` | 상황을 확인하는 기본 자세. |
| N3 | `char_doyun_normal_startled.png` | 회색 망령 등장에 놀란 상태. |
| N4-A / N4-B / N4-C | `char_doyun_normal_smile.png` / `char_doyun_normal.png` / `char_doyun_normal_shy.png` | 변신 직전 관계 온도를 짧게 반영한다. |
| N5 주문 전·영창 | `char_doyun_normal_shy.png` | 체면 때문에 망설이지만 행동하는 상태. |
| N5 변신 완료 | `char_doyun_magical_pose.png` | 변신 결과 화면과 전투 진입 사이에 표시한다. |
| N6~N8 전투 | `char_doyun_magical_defend.png` / `char_doyun_magical_attack.png` / `char_doyun_magical_finish.png` | 실제 선택과 페이즈에 맞춰 사용한다. |
| 전투 후 수렴 | `char_doyun_magical_pose.png` | 변신 상태를 유지한 채 마지막 답을 내린다. |
| GOOD / NORMAL / BAD | `char_doyun_normal_smile.png` / `char_doyun_normal_smile.png` / `char_doyun_normal_empty.png` | 엔딩 정서에 맞춰 평상복으로 돌아온다. |

## 주노 행동 variation 메모

기존 표정 `neutral`, `happy`, `shy`, `upset`, `surprised`는 유지한다. 다음은 신규 표정 ID가 아니라 행동 실루엣 후보다.

- `[POSE] point/explain` — 도윤 또는 화면을 가리키며 짧게 설명.
- `[POSE] urgent/forward` — 위험을 감지하고 앞을 막거나 전진.
- `[POSE] barrier/protect` — 방어막을 펼쳐 도윤을 보호.
- `[POSE] encourage/cast` — 함께 주문을 외치거나 도윤을 격려.

# N0. 반복되는 심사

## 장면 목적

- 도윤의 권태와 직업적 태도를 동시에 보여 준다.
- 도윤이 투덜거리면서도 제출물을 직접 실행하는 사람임을 행동으로 보여 준다.
- 회색 망령이 사용할 평가 문장을 미리 심는다.
- N7의 `happy_break`를 설명 없이 노출한다.

## 배경

늦은 밤의 사무실. 여러 심사역이 각자 출품작을 확인한다.

## 장면

도윤의 모니터에서 평가표가 연속으로 넘어간다.

```text
완성도는 양호하나 차별성이 부족함.
기존 작품과 유사한 경험을 제공함.
추가적인 개선이 필요함.
```

도윤의 커서가 마지막 문장을 복사한다. 다음 작품의 평가표에 붙여 넣으려다 멈춘다.

바탕화면 구석에 오래된 폴더 하나가 있다.

```text
happy_break_v0.3
```

도윤은 폴더를 설명하거나 열지 않는다. 커서가 잠깐 스쳐 지나갈 뿐이다.

`[PRESENTATION] happy_break 폴더는 한 번만 짧게 보이고 강조 효과나 회상 음향을 넣지 않는다.`

## 화면 독백

> 제출물이 끝이 없다.  
> 이러다 진짜 밤을 새우겠다.

다음 제출물의 제목이 나타난다.

```text
심사역은 마법소녀가 되었다
```

플레이어가 제목을 확인할 수 있을 만큼 짧게 멈춘다.

> **도윤의 내적 반응**  
> 제목은 거창하네.

도윤은 평가표만 읽고 넘기지 않는다. 게임을 직접 실행한다.

화면 속 작은 게임 캐릭터가 도윤을 향해 손을 흔든다. 앞서 본 작품과 익숙한 구성이라도 도윤은 종료 버튼을 누르지 않고 다음 상호작용까지 진행한다.

`[POSE] 도윤이 피곤한 얼굴로 화면을 의심스럽게 보는 반응.`

잠시 후 화면에 음성 입력 안내가 뜬다.

> **[직접 말해 주세요]**  
> 지금 떠오르는 생각을 말해 보세요.

## 플레이어 발화 예시

- “결국 다 비슷하네.”
- “뭐 신박한 게임 없나.”
- “빨리 끝내고 집에 가고 싶다.”
- “이 게임은 좀 괜찮으려나.”
- 엉뚱한 자유 발화

긍정적인 말을 해야만 사건이 시작되는 것은 아니다. 도윤이 게임을 직접 실행하고 여기까지 확인했다는 행동이 선택의 근거다.

## 장면 반응

플레이어의 말이 끝나는 순간:

- 게임 캐릭터의 움직임이 멈춘다.
- 사무실 시계 초침이 멈춘다.
- 화면의 색이 아주 조금 빠진다.
- 도윤의 사원증이 희미하게 빛난다.

`[PRESENTATION] 시계 정지, 화면 desaturation, 사원증 발광, 모니터 미세 flicker.`

## 전환

모니터 중앙에 문구가 나타난다.

> **지금 가장 원하는 것을 말해 주세요.**

N1로 이동.

# N1. 첫 번째 목소리

## 장면 목적

- 음성이 게임 속 행동임을 자연스럽게 학습시킨다.
- 발화 내용에 따라 첫 응답의 온도만 바꾼다.
- 냉소적이거나 피곤한 발화여도 주노가 등장하는 논리를 유지한다.

## 플레이어 발화

플레이어는 지금 원하는 것을 자유롭게 말한다.

### 분류 A — 새로운 재미·게임·자극

- “진짜 재미있는 게임.”
- “신박한 거 하나만 나왔으면.”
- “좀 설레는 일이 있었으면 좋겠다.”

### 분류 B — 퇴근·휴식·잠

- “집에 가고 싶다.”
- “자고 싶다.”
- “오늘 일 좀 끝났으면.”

### 분류 C — 의심·무응답·기타

- “누구세요?”
- “이게 뭐야?”
- 인식 가능한 기타 발화

## 화면

> 다음에는 네 말을 더 오래 들을게.

모니터 검은 화면에 회색 원형이 천천히 회전한다.

# 엔딩 D. HIDDEN — 완벽한 호흡, 완벽한 사고

## 진입 전제

- 변신 주문을 완벽하게 낭독함.
- 조건부 두 번째 주문 기회를 얻어 방어와 공격을 모두 사용함.

- N8에서 최종 주문에 성공함.

정확한 수치·flag 조건은 대본 외 구현 계약에서 확정한다.

## 장면

평가표 수정까지 GOOD과 동일하다.

저장 직후 회사 단체 메신저 알림이 연속으로 울린다.

```text

한도윤 심사역 마법소녀 변신 영상
```

> **주노**  
> 변신 장면은 자동으로 기록돼!

플레이어가 항의하면:

> **주노**  
> 그런 설정은 방금 만들었어!

플레이어가 퇴사·삭제·도망과 관련된 말을 하면:

> **주노**  
> 다음 심사도 같이 해야 하니까 도망가면 안 돼!

화면 암전.

```text
HIDDEN END
완벽한 호흡, 완벽한 사고
```

# Post-credit stinger — 검은 마법소녀

## 적용

- GOOD 또는 HIDDEN 크레딧 이후.
- GOOD 본편의 감정적 완결을 깨지 않도록 별도 장면으로 시작한다.
- 대규모 회색 잔향 `1,024` 수치는 사용하지 않는다.

## 장면

어두운 복도.

긴 검은 지팡이 끝이 바닥에 닿는다. 주변에 남은 회색 잔향이 지팡이 끝으로 빨려 들어간다.

`[CUT] 검은 지팡이와 회색 잔향 흡수, 얼굴과 이름은 감춘 성인 여성 실루엣.`

> **정체불명의 목소리**  
> 두근두근 용기 한 스푼.

> **정체불명의 목소리**  
> 반짝반짝 설렘 두 스푼.

주노의 날갯짓이 멈춘다. 오래된 지팡이 문양과 원형 주문을 바라본다.

> **주노**  
> 저 주문은 오래전에 버렸어.

> **주노**  
> 이제 아무도 쓸 수 없어야 해.

주노는 여성의 이름을 부르지 않으며 정체를 확정하지 않는다.

검은 마법소녀가 지팡이를 도윤 쪽으로 돌린다.

> **정체불명의 목소리**  
> 당신의 마음에 즐거움을 로그아웃.

검은빛이 화면을 삼킨다.

`[PRESENTATION] 검은빛이 복도 가장자리부터 UI까지 흡수하고 마지막에 음성 파형이 사라진다.`

```text
《심사역은 마법소녀가 되었다》
TO BE CONTINUED
```

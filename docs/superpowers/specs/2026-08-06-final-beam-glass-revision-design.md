# 최종 빔·결정 파괴 3레이어 보정 설계

## 승인 범위

사용자 승인일: 2026-08-06

기존 `최종 빔 + 결정 파괴` 2파일 구조를 아래 3파일로 교체한다.

1. `sfx_final_beam_charge.wav` — 합성 에너지 `우웅–우웅` 충전
2. `sfx_final_beam_fire.wav` — 레이저 방출·빔 몸통
3. `sfx_final_crystal_break.wav` — 실제 유리 중심의 큰 크리스탈 파괴

게임 runtime 연결과 코드 변경은 개발자 범위다. 본 작업은 Suno Sounds 제작폼과 인계 문서만 변경한다.

## 리서치 근거

SF 무기 제작에서는 충전, 에너지 방출, 실제 발사를 분리된 레이어로 관리한다. 충전은 상승하는 음높이와 빨라지는 맥동을 사용하고, 발사는 짧은 공격점과 하강 피치로 방출을 읽힌다.

- <https://www.asoundeffect.com/supreme-scifi-weapon-sound-effects/>
- <https://designingsound.org/2018/08/21/making-a-plasma-gun-from-a-beer-can/>
- <https://www.asoundeffect.com/star-wars-jedi-survivor-game-audio/>

유리 파괴는 최초 노이즈 파열 뒤 불규칙한 다중 감쇠 파편이 이어져야 파괴로 인식된다. 실제 유리 성분은 광대역 고주파 파쇄가 중심이며, 크리스탈 정체성은 짧은 맑은 공명을 추가해 만든다.

- <https://pubmed.ncbi.nlm.nih.gov/6238128/>
- <https://patents.google.com/patent/US5831528A>
- <https://www.prosoundeffects.com/libraries/sonomar-collection-crystal-sing>
- <https://www.boomlibrary.com/sound-effects/debris/>

참고 자료의 원본 음원은 복제·샘플링·납품하지 않는다.

## 1. 최종 빔 충전

### 음향 구조

1. 첫 번째 낮고 넓은 합성 에너지 `우웅`
2. 더 높고 빠르며 강한 두 번째 합성 에너지 `우웅`
3. 입자가 안쪽으로 모이며 끝나는 짧은 power-lock

### 규격

- 계약명: `sfx_final_beam_charge.wav`
- 목표 길이: 0.9–1.2초
- 중심 인상: 에너지 축적, 두 번의 명확한 맥동, 발사 직전 긴장
- 제외: 실제 사람 목소리, 발사음, 충돌, 폭발, 음악, 긴 드론, fade-out

### 성공 기준

- `우웅–우웅`이 두 번 구분된다.
- 두 번째 맥동의 음높이와 진동 속도가 첫 번째보다 높다.
- 발사음 없이 power-lock에서 깨끗하게 끝난다.

## 2. 최종 빔 발사

### 음향 구조

1. 지연 없는 밝고 날카로운 에너지 방출 스냅
2. 빠르게 하강하는 레이저 피치
3. 짧고 집중된 pink-white 빔 몸통
4. 결정 파괴음을 덮지 않는 짧은 꼬리

### 규격

- 계약명: `sfx_final_beam_fire.wav`
- 목표 길이: 0.6–0.9초
- 중심 인상: 충전된 에너지의 즉시 방출, 선명한 레이저, 강한 피니시
- 제외: 선행 충전, `우웅` 맥동, 충돌, 결정 파괴, 폭발, 총성, 반복 발사, 긴 잔향

### 성공 기준

- 첫 0.1초 안에 발사가 인식된다.
- 충전음과 붙였을 때 하나의 연속 동작으로 들린다.
- 끝부분에 결정 파괴음을 겹쳐도 발사와 파쇄가 모두 읽힌다.

## 3. 최종 결정 파괴

### 음향 구조

1. 큰 두꺼운 유리 크리스탈의 즉시 발생하는 최초 균열
2. 불규칙한 고주파 유리 파편 다수의 파쇄
3. 단단한 바닥에 짧게 떨어지는 작은 파편
4. 마법 크리스탈 정체성을 주는 짧고 맑은 고조파 공명

### 규격

- 계약명: `sfx_final_crystal_break.wav`
- 목표 길이: 0.7–1.0초
- 중심 인상: 실제 대형 유리 파괴가 우선, 짧은 크리스탈 공명이 보조
- 제외: 마법 폭발 중심음, 돌 붕괴, 얼음 균열, 병·와인잔, 빔·위시, 긴 반짝임

### 성공 기준

- 첫 트랜지언트만 들어도 유리가 깨진 것으로 들린다.
- 한 번의 큰 균열 뒤 여러 불규칙한 파편이 들린다.
- 병이나 작은 잔이 아니라 큰 두꺼운 유리 크리스탈로 들린다.
- 크리스탈 공명은 파쇄를 가리지 않는다.

## 장면 동기화 계약

```text
충전 시작             발사 프레임                   결정 충돌 프레임
sfx_final_beam_charge  sfx_final_beam_fire          sfx_final_crystal_break
0.9–1.2초              0.6–0.9초                    0.7–1.0초
```

개발자는 충전 파일 끝과 발사 파일 시작을 맞춘다. 결정 파괴 파일은 발사 파일의 실제 충돌 프레임에 겹친다.

## 생성·선택 규칙

- Suno Sounds `v5.5`, `One-Shot`, `BPM Auto`, `Key Random`
- 각 항목 2회 생성해 후보 4개 비교
- 음성·음악·반복·긴 도입이 생기면 폐기
- 생성 WAV는 자르거나 정규화하지 않고 원본으로 전달
- 기존 `sfx_final_beam.wav` 계약은 폐기 예정으로 표시하고 새 충전·발사 계약으로 대체

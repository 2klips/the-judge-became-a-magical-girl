# 늦은 밤 공동 야근 시나리오·에셋 연속성 설계

- 작성일: 2026-08-13
- 기준 커밋: `fbe58084065a931cf9beaf97a2665d2a39dbb7bb`
- 화면 범위: 데스크톱 16:9. 모바일 검수 제외
- 상태: 사용자 권장안 진행 승인 반영

## 1. 목적

N0부터 변신·전투까지를 **핵심 심사팀이 함께 늦은 밤까지 야근하는 같은 밤**으로 통일한다. 현재 대본의 `도윤만 남음` 및 `주변에는 아무도 없음` 문장, 밝은 낮·석양 배경, 비어 있는 전투 사무실을 함께 바로잡는다.

GOOD 엔딩의 아침은 오류가 아니라 밤샘 뒤의 시간 경과로 유지한다. 마법 전투 직후 아침으로 갑자기 바뀌지 않도록 짧은 시간 연결 문장을 추가한다.

## 2. 검토한 방식과 선택

### A. CSS 야간 필터만 적용

가장 빠르지만 밝은 창밖 하늘과 빈 좌석은 그대로 남는다. 실제 primary 배경에는 현재 CSS 야간 필터도 적용되지 않는다. 설정 충돌을 해결하지 못해 제외한다.

### B. 대본과 핵심 배경을 함께 보정 — 선택

대본은 `핵심 심사팀 잔류 + 마법에 의해 인식 정지`, 이미지는 `동일한 늦은 밤 광원 + 멀리 있는 비식별 동료`로 맞춘다. 기존 구도·주연 캐릭터·논리 ID를 재사용해 연속성과 제작비를 균형 있게 확보한다.

### C. 모든 사무실 배경과 동료 캐릭터 전면 재제작

표현력은 높지만 신규 인물 디자인, 표정 스프라이트, 장면별 배치가 필요하다. 데모 범위를 크게 넘으므로 제외한다.

## 3. 확정 이야기 규칙

- N0 시작부터 핵심 심사팀 여러 명이 각자 자리에서 야근한다.
- 일부 빈 자리는 허용하지만 도윤만 홀로 남았다고 서술하지 않는다.
- 주노 등장 뒤 마법 영향으로 동료들의 시간과 인식이 멈춘다.
- 도윤의 변신은 동료가 사라져서가 아니라 동료가 인식할 수 없어서 가능하다.
- 전투의 보호막은 정지된 동료와 심사 중인 게임 화면을 지킨다.
- GOOD에서는 마법이 끝나 시간이 다시 흐르고, 긴 밤 뒤 아침이 온다.
- NORMAL/BAD/HIDDEN의 기존 의미와 분기 조건은 바꾸지 않는다.

권장 핵심 문구:

- N0: `늦은 밤, 도윤과 동료들의 모니터에 평가표가 이어진다.`
- N5: `다들 시간이 멈춰서 듣지 못해. 마음껏 외쳐!`
- GOOD 전환: `멈췄던 시간이 다시 흐른다. 긴 밤 끝에 아침빛이 사무실로 들어온다.`

## 4. 이미지 연속성 규칙

### 공통 불변식

- 1920×1080 WebP, 데스크톱 16:9
- 기존 카메라·사무실 구조·가구 배치 유지
- 주연 얼굴·체형·포즈·의상·손·지팡이·주노 정체성 유지
- 창밖은 짙은 남청색 밤하늘. 직접 태양광·석양·새벽빛 금지
- 실내 광원은 모니터 청색과 천장·스탠드의 따뜻한 인공조명
- 동료는 멀리 있는 비식별 실루엣 또는 흐린 뒷모습만 사용
- baked text, UI, 개인정보, 로고, 워터마크 금지
- 새 이름 있는 동료 캐릭터나 얼굴 클로즈업 금지

### 대상별 계약

1. `bg_office_wide`: 기존 와이드 구도 유지. 3~5명의 멀리 앉은 동료와 켜진 모니터를 보여 N0 공동 야근을 확립한다.
2. `bg_hall_dark`: 밝은 창밖을 늦은 밤으로 변경한다. 회색 침식과 책상 구도는 유지하고 동료는 멀리 정지된 실루엣으로만 둔다.
3. `bg_transform_space`: 석양을 밤으로 변경한다. 마법 공간과 원근은 유지하고 멀리 정지된 동료 흔적을 약하게 남긴다.
4. `cut_transform_01`: 직전 채택 야간 베이스를 사용한다. 인물·배경을 재구성하지 않고 A2 사원증 내부 백금색 별빛 발광만 보정한다. 단단한 추가 사각 테두리 금지.
5. `cut_transform_02`: 도윤·주노·의상·지팡이·포즈를 고정하고 창밖과 실내 광원만 늦은 밤으로 바꾼다. 동료는 필요할 때만 먼 배경의 정지 실루엣으로 둔다.
6. `bg_battle_wide`: 낮 배경을 같은 밤으로 바꾸고, 보호받는 동료를 먼 좌석 실루엣으로 표현한다. 전투 UI와 주연 스프라이트 가독 영역은 비운다.
7. `bg_battle_core`: 석양 광원을 밤으로 바꾼다. 회색 핵과 전투 초점은 유지하고 동료는 침식·보호막 뒤에 흐리게 처리한다.

`bg_desk_closeup`, `bg_hall_void`, `bg_mind_archive`, 엔딩·복도 배경은 이번 이미지 수정 대상이 아니다. 시간대가 직접 드러나지 않거나 엔딩 시간과 이미 맞는다.

## 5. 파일·데이터 경계

시나리오 SSOT와 실제 런타임을 함께 수정한다.

- `docs/심사역은_마법소녀가_되었다_완성대본_v2.md`
- `public/scenario/scenario.json`
- 시나리오 연속성 회귀 테스트

에셋은 기존 runtime 파일을 교체한다. 생성 결과의 보존본은 `assets/source` 아래 delivery 구조로 저장하고 runtime과 동일 바이트를 유지한다. 기존 배경 원본 ZIP은 수정하거나 복제하지 않는다.

- `assets/runtime/bg/bg_office_wide.webp`
- `assets/runtime/bg/bg_hall_dark.webp`
- `assets/runtime/bg/bg_transform_space.webp`
- `assets/runtime/bg/bg_battle_wide.webp`
- `assets/runtime/bg/bg_battle_core.webp`
- `assets/runtime/cut/cut_transform_01.webp`
- `assets/runtime/cut/cut_transform_02.webp`
- 대응 `assets/source/.../delivery` 보존본

논리 ID, catalog 경로, 분기 조건, 게임 엔진 동작은 바꾸지 않는다.

## 6. 제작·비용 절감 방식

- 새 그림을 처음부터 만들지 않고 각 기존 이미지를 edit target으로 사용한다.
- 배경은 조명·창밖·먼 동료만 바꾸는 `lighting-weather` 및 국소 편집으로 제한한다.
- 동료 얼굴·새 스프라이트를 만들지 않아 캐릭터 일관성 검수 비용을 피한다.
- 각 이미지에서 구도나 주연이 드리프트하면 채택하지 않는다.
- 한 번에 모든 이미지를 덮어쓰지 않고 후보를 원본과 비교한 뒤 채택한다.

## 7. 검증 기준

### 자동

- 대본과 runtime에 `도윤만 남음`, `마지막까지 남은 도윤`, `주변에는 아무도 없어`가 남지 않음
- 공동 야근, 시간 정지, GOOD 아침 연결 문구 존재
- 모든 대상 WebP 1920×1080
- 배경 500KB 이하, 변신 컷 700KB 이하
- 모든 source/runtime 대응본 동일 SHA-256
- `npm run check`, `npm test`, `npm run build` 통과

### 데스크톱 화면

- N0에서 여러 사람이 늦은 밤 함께 야근한다고 즉시 읽힘
- N0 → N3 → N5 → 변신 두 컷 → battle p1/p3가 같은 밤·같은 사무실로 이어짐
- 동료가 주연/UI를 가리지 않고 시간 정지 상태로 읽힘
- `cut_transform_01`의 기존 파란 홀더 림과 손가락 유지, 부드러운 A2 발광만 존재
- `cut_transform_02`와 마법소녀 스프라이트의 의상·지팡이·주노 연결 유지
- GOOD에서 밤샘 뒤 아침 전환이 의도적으로 읽힘
- 1280×720에서 overflow 0, console error 0

# N5 변신 영창 컷 포즈 수정 설계

- 작성일: 2026-08-11
- 브랜치: `codex/p0-required-image-assets`
- 대상 논리 ID: `transform.cast`
- 대상 파일: `assets/source/p0-required-images/delivery/cut_transform_01.webp`, `assets/runtime/cut/cut_transform_01.webp`
- 상태: 사용자 디자인 승인·2026-08-11 데스크톱 범위로 개정

> **2026-08-11 사용자 개정:** 이 포즈 수정의 제품 범위에서 모바일을 제외한다. `390×844`와 세로형 crop은 생성·채택·브라우저 완료 기준이 아니며, 데스크톱 16:9만 기준으로 삼는다. 기존 이미지 경로를 그대로 교체하므로 CSS·코드 변경도 하지 않는다. 아래 A 균형형 구도 선택은 유지하되, 설계 과정에서 검토했던 모바일 안전 영역 요구는 이 개정으로 대체됐다.

## 1. 배경과 문제

수정 전 영창 컷은 평상복 도윤, 떠 있는 무문자 사원증, 주노, 변신광을 보여 주어 `변신 전 → 영창 → 변신 완료` 순서는 맞았다. 그러나 도윤이 입을 손으로 가리고 사원증이 인물과 분리되어 떠 있어, 두 인물이 함께 주문을 수행한다는 동작이 약했다.

사용자는 다음 세 가지 수정을 요청했다.

1. 도윤이 사원증을 카메라 앞으로 직접 내민다.
2. 도윤의 입이 실제로 주문을 말하는 모양으로 보인다.
3. 주노가 기도하는 듯한 동작을 한다.

## 2. 목표와 제외 범위

### 목표

- 한 장만 보아도 도윤과 주노가 함께 영창 중이라는 사실이 읽힌다.
- 사원증이 변신 매개체이며 도윤이 직접 내미는 물체라는 관계가 분명하다.
- 도윤은 변신 전 평상복을 유지한다.
- 16:9 데스크톱 화면에서 도윤의 입, 사원증, 주노가 함께 읽힌다.

### 제외 범위

- `transform.complete`와 다른 캐릭터·배경·BGM·SFX는 수정하지 않는다.
- 코드, catalog, 시나리오, 변신 컷 재생 순서, runtime 동작을 수정하지 않는다.
- 모바일 crop 대응과 그를 위한 CSS·레이아웃 변경은 수행하지 않는다.
- 사원증에 이름·회사·사진·로고·문자·UI를 넣지 않는다.
- 신규 논리 ID나 추가 컷을 만들지 않는다.

## 3. 선택한 구도 — A 균형형 중경

- 도윤은 화면 중앙에서 허벅지 위까지 보이는 중경으로 현재보다 가깝게 배치한다.
- 도윤은 한 손으로 사원증을 좌측 전경에 내민다. 사원증은 화면 면적 약 25%를 차지하고, 원근에 따라 손과 몸보다 크게 보인다.
- 손가락은 사원증 가장자리 또는 클립을 자연스럽게 잡아야 한다. 사원증이 손과 분리되어 떠 보이면 실패다.
- 도윤의 다른 손은 가슴 가까이 두어 긴장과 영창 집중을 표현하되 얼굴과 입을 가리지 않는다.
- 도윤의 입은 또렷하게 주문을 외치는 중간 크기로 연다. 과장된 함성보다 진지하고 약간 부끄러운 표정을 유지한다.
- 주노는 화면 오른쪽에서 눈을 감고 두 날개를 가슴 앞에 모아 기도한다. 별 지팡이는 두 날개 사이에 세로로 세운다.
- 사원증, 도윤, 주노가 서로 과도하게 겹치지 않게 삼각형 시선 흐름을 만든다.

## 4. 유지해야 할 시각 요소

- 야간 사무실과 청색·금색 변신광, 원형 마법진, 별빛 입자를 유지한다.
- 도윤은 흰 셔츠, 검은 넥타이, 검은 바지의 평상복 성인 남성이다. 마법소녀 의상·리본·치마·장식은 금지한다.
- 도윤의 검은 웨이브 머리와 기존 캐릭터 화풍을 유지하되 입은 보여야 한다.
- 주노의 노란 병아리형 몸, 별 목걸이, 별 지팡이, 기존 화풍을 유지한다.
- 사원증은 화면에 정확히 하나만 둔다. 목걸이형 중복 사원증이나 배경 속 추가 사원증은 금지한다.
- 텍스트, 말풍선, 로고, 워터마크, 게임 UI를 이미지에 굽지 않는다.

## 5. 제작 방식과 실패 처리

- 현재 `cut_transform_01.webp`를 편집 대상으로 사용한다.
- 기존 도윤·주노 캐릭터 파일은 정체성·의상·화풍 참고 자료로만 사용한다.
- Codex 내장 OpenAI 이미지 편집 도구로 후보를 만들고, 현재 채택본을 즉시 덮어쓰지 않는다.
- 후보에서 인물 수, 손가락, 사원증 개수, 입 모양, 주노의 두 날개·지팡이 결합을 먼저 시각 검수한다.
- 한 항목만 어긋나면 전체를 새로 확장하지 않고 해당 항목만 지정해 한 번씩 수정한다.
- 최종 후보만 1920×1080 WebP로 정규화해 source/runtime 두 경로에 동일 바이트로 채택한다.
- 생성 후보가 현재본보다 장면 정합성이 낮으면 채택하지 않고 Git의 기존 파일을 유지한다.

### 사람·브라우저 검증

- 도윤의 손과 사원증이 연결돼 앞으로 내미는 동작으로 읽힌다.
- 도윤의 입이 가려지지 않고 중간 크기의 발화 모양으로 보인다.
- 주노가 눈을 감고 기도하며 지팡이를 두 날개 사이에 세운다.
- 도윤은 영창 컷에서 평상복이고 완료 컷에서만 마법소녀 복장이다.
- 1280×720 데스크톱 N5 변신 프리뷰에서 핵심 세 요소가 보이고 가로 overflow와 console error가 없다.
- 사람 미술·권리 QA 전 상태는 `ready`이며 `approved`로 승격하지 않는다.
